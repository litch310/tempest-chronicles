# Tempest Chronicles

A real-time strategy game of four warring factions. Gather resources, raise an army, and crush your
rivals — against the computer or against friends.

## Download

| Platform | File | Notes |
|----------|------|-------|
| **Windows** (64-bit) | `TempestChronicles-Windows.zip` | No install. Unzip it, open the `TempestChronicles` folder and double-click `TempestChronicles.exe`. |
| **Android** (64-bit / arm64) | `TempestChronicles.apk` | Sideload it (see below). |

Grab the files from the [**latest release**](../../releases/latest).

## The game

- **Four factions**, each with its own units, buildings and tech: **the Vanguard** of Izare, **the Frost Fang**
  of Fernar, **the Legion** of the undead Litch, and **the Tide Bringers** from the deep of the Aegean.
- **Skirmish** — battle the computer on the battlefield and difficulty you choose.
- **Multiplayer** — Blood Feud: play with friends online with a room code, up to four players.
- **Hero parties** — each faction can hire a band of heroes, every one with its own attack and skill.
- **Thirteen battlefields** to fight over: frozen rivers, grasslands, deserts, islands and open sea.
- **A living battlefield** — grass bends under marching feet, snow takes footprints, and fords ripple and splash.

Select units with the mouse (tap and drag on Android) and give orders from the command card; each
order has a hotkey.

## Installing the Android APK

Android blocks apps from outside the Play Store by default, so:

1. Copy `TempestChronicles.apk` to your phone (or download it there).
2. Open it with a file manager.
3. When Android warns about an unknown app, allow installing from this source, then tap **Install**.

If the new version won't install over an older one, uninstall the old version first.

Needs a 64-bit (arm64) Android device, which covers essentially all phones from the last several years.
